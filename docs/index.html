Why this guide

مدل ذهنی، نه حفظ API

هر مفهوم اول روی مدل اجرای موتور می‌نشیند؛ بعد در کد واقعی و مینی‌پروژه پیاده می‌شود.

مدل ذهنی زبان، روشن
می‌فهمی موتور چطور فکر می‌کند: Scope، Closure، this و Prototype — نه فقط چه سینتکسی بنویسی.
همگام با ES2025
قابلیت‌های مدرن مثل using، متدهای Set و Promise.withResolvers کنار مرزبندی روشن با کد Legacy.
ناهمگامی عمیق
‏Event Loop، صف Microtask، Promise و async/await؛ می‌دانی چرا ترتیب اجرا همان است که هست.
V8 و Performance
‏Hidden Class‏، بهینه‌سازی TurboFan‏، ‏Garbage Collection‏ و شکار Memory Leak با نگاه عملی.
امنیت و تست
XSS‏، Prototype Pollution‏، مدیریت خطا و تست مدرن؛ کدی که در Production قابل دفاع باشد.
کارگاه و مصاحبه
هشت مینی‌پروژه، بیست نکتهٔ طلایی و سی‌وسه جعبهٔ پرسش مصاحبه از Junior تا Senior.

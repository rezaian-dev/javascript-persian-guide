## Map vs Object

| ویژگی | Map | Object |
|---|---|---|
| کلید | هر نوع | فقط string/symbol |
| اندازه | size | keys().length |

```js title="map.js"
const map = new Map();
map.set({id:1}, "Ali");
const keyObj = {id:1};
map.set(keyObj, "Ali");
map.get(keyObj);

```

## Set

```js title="set.js"
const set = new Set([1,2,2,3]); // {1,2,3}
const unique = [...new Set([1,2,2,3])];
const a = new Set([1,2,3]); const b = new Set([2,3,4]);
a.intersection(b); // {2,3}

```

## WeakMap

```js title="weak.js"
const cache = new WeakMap();
function getData(obj) {
  if (cache.has(obj)) return cache.get(obj);
  const data = heavyCompute(obj);
  cache.set(obj, data);
  return data;
}

```

:::interview
**Mid — چرا Map بهتر از Object برای کلید شیء؟** Object کلید را به رشته تبدیل می‌کند.
:::
